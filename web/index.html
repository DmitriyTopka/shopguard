ShopGuard on Otari

An honesty guard for shop chatbots. Before a bot's reply reaches the customer, every promise in it (price, stock, installments, delivery, product specs) is checked against the shop's own data and the open web, and fixed if it is not true. Demo store, fictional prices, real product specs. Watch the 3-minute demo video.

How it works

  1. Draft. A sales bot (Gemma 3 27B through Otari) writes a reply. Or paste a reply from any bot you already run.
  2. Extract. Nemotron Nano lists every promise in the reply as JSON. A regex net also catches any amount of money or number of payments, so nothing slips through if extraction misses it.
  3. Check. Prices, stock, installments and delivery are checked by plain code against the catalog and the policy: exact and free. For product specs Nemotron Super searches the web through Otari's built-in web search tool and judges whether the sources back the claim.
  4. Fix. If anything is wrong or unconfirmed, Nemotron Super rewrites the reply using only the correct facts, and the rewrite is checked again. If it still fails, a safe hand-off to a manager is sent instead.

Demo store "KitchenHub": prices and stock are fictional, product models and specs are real. No real customer data is used. Every model call goes through the Otari gateway; code: github.com/DmitriyTopka/shopguard.
